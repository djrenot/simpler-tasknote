# Simpler Tasknote

とてもシンプルなTODOリストです。名前をつけて、終わったらチェックをつけるだけ。  
名前・期限・メモでソートができます。  
箇条書きスタイルで、タスク一覧（完了済みのみ・全タスク）をコピーできます。  

ログイン不要。ユーザー情報は一切取得していません。  
リストはブラウザ依存(Local Storage)で保存されるので、環境次第で消えることがあります。  

その日のタスク覚書きとして使うのがちょうどいいはずです。  

Very simple todo list. Name it, tick it out, that's it.  
You can re-order by name, deadline, note.  
You can copy the list as bullet list style. Done tasks only or whole list.  

No login needed. We don't collect any user info.  
Tasks are store to your web browser (Local Storage) so it might be gone depends on your condition.  

It's best to use as a pseudo todo list for today.
